# Source snapshots for the Kozuch Football Performance Complex

Retrieved 2026-10-26. Images are preserved as modeling references only, not used as image textures.

- `purdue_gis_fpc_fid1202_2026-10-26.geojson` — Purdue Libraries campus GIS, MapServer layer 0 / FID 1202, `Kozuch Football Performance Complex`, output CRS EPSG:4326. The service itself is EPSG:3857. Local Blender coordinates use the project approximation documented in the model evidence.
- `purduesports_kfpc_facility_page_2026-10-26.html` — Purdue Athletics facility page. Identifies the address, opening, three levels, 112,000 square feet, interior program and entrance lobby.
- `purdue_athletics_kfpc_exterior.jpg` — Purdue Athletics image of the entrance canopy, P sign, 1228 number, glazing and metal cladding. Image URL: https://storage.googleapis.com/purduesports-com-prod/2025/05/16/htD6quX54pbWbUUgrDVyK0IGFdpIrbJr5IEgvNrh.jpg
- `populous_kfpc_architect_page_2026-10-26.html` — project architect page with the flight-inspired two-plane roof description, glass curtain wall and Purdue palette.
- `frp_kfpc_entrance_photo.jpg` — FRP project entrance photo showing glass curtainwall, angled stainless columns, canopy and address. Page: https://frpinc.com/projects/purdue-university-football-performance-complex/
- `purdue_archives_building_318_2026-10-26.html` — Purdue Archives facility record identifying the building as three levels and adjoined to Mollenkopf's north end.

No building image was used as a facade texture. Exterior materials in the model are procedural Blender materials.
- `esri_world_imagery_context_2026-10-26.jpg` — Esri World Imagery around the football performance complex, accessed 2026-10-26. Export request bbox: `[-86.9181, 40.4338, -86.9154, 40.4372]`, EPSG:4326; image export response expanded the longitude extent to `[-86.9190166667, -86.9144833333]` for its 1600x1200 aspect ratio. Actual imagery vintage is not exposed. `../gis_footprint_on_esri_imagery.png` overlays the GIS polygon using the returned extent and shows the FPC roof alignment.
